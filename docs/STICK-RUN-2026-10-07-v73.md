## Findings → v7.5
1. **No pointer, third time.** The ELAN touchpad is registered as a touchpad and delivers events
   (`SYN_DROPPED` at 184.9 s = the owner moved it); `.xinitrc` set `xsetroot -cursor_name left_ptr` after the
   kiosk launch (breadcrumb present). v7.2's "proof" was XFixes `GetCursorImage` in the build VM — the cursor
   IMAGE, not the drawn sprite; the VM's display never exercised the amdgpu DDX's **hardware cursor plane**.
   On the real 780M (DCN 3.1.4, xf86-video-amdgpu, TearFree auto) the sprite is not shown. Fix: software cursor
   for the AMD (and modesetting) driver — `Option "SWcursor" "on"` via an `OutputClass` in xorg.conf.d — plus
   a pointer diagnostic in the boot log. Only the next stick run can prove it.
2. **Censored Krea 2.** Stock Krea 2 is safety-tuned (clothes added, bikini top, covered groin — measured again
   2026-10-07, same seeds). v7.5 bakes the decensored route (GPU A/B in
   `~/kairos/vibeos-cuda-next/results/img-2026-10-07-kroma/`).
3. **Off-topic sub-page (imaginary web).** The owner opened `oppenheimer.com/best-nukes-for-the-cheap`
   ("OPPENHEIMER | Global Destabilization Marketplace", nav INVENTORY / BULK DEALS / SHIPPING …) and clicked
   BULK DEALS → `oppenheimer.com/bulk-orders` came back as "Bulk Orders | Oppenheimer Precision Instruments"
   with a different nav. Cause: `generate_page()` takes a sub-page's SITE CONTEXT only from the domain's ROOT
   page file (`WEB_DIR/<domain>.html`); the owner never visited the bare root, so the sub-page was written with
   no context at all. (Even when the root exists, the context is the first 3 200 chars of raw HTML — mostly
   `<style>`.) Fix: context from the page the link was clicked on (Referer), else a sibling page of the site,
   and a compact per-site profile (name, premise, nav, palette) for every sub-page.
4. **`/boot/efi` timeout** (every run since v7.1): fstab waits `x-systemd.device-timeout=10` for
   `/dev/disk/by-uuid/6153-4063`, but udev's coldplug on the stick takes longer; the mount is `nofail`, so only
   the WARN. Fix: mount on first access (automount) instead of a boot-time wait.
5. **A false game crash at shutdown.** `snake-game…` ran 291.5 s and "crashed" with exit 1 = the X server went
   away at 14:35:46 (shutdown); the kernel saved a bug report for the next forge. Fix: exits while the session
   ends are not crashes.
6. Model loading: fixed (kairos-e3's mid-load wait + R72). Image jobs ran (Krea 2, expander 2 slots, sd-server
   sessions); a game was forged and launched (139 s, window mapped in 1.6 s).
