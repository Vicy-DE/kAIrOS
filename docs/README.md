# docs/ — index

Two kinds of documents live here: the **living references** (requirements, design, the API the
coder LLM reads) and about forty **dated reports** — the project's lab notebook. A report is
written once, during the work it describes, and is not updated afterwards; where a later report
supersedes it, that is noted below. Dates are in the file names (`<TOPIC>-<YYYY-MM-DD>.md`).

## The state these documents describe (2026-10-14, v7.5-1)

- **Default LLM (8 and 16 GB tiers):** Gemma 4 26B-A4B-it *ultra-uncensored heretic*, i1-IQ4_XS,
  marked `"uncensored": true` in the manifests: it answers adult requests itself; R86's refusal
  ladder (the same model with an 18+ preamble, then the uncensored model) covers a model that still
  declines, and a narrow minors block refuses only a request that pairs an explicit under-18 age or
  word with a sexual term (plus a few illegal-content terms). No separate fast model since 2026-10-18 (R89):
  the Qwen2.5-Coder-7B add-on left the tiers, and on 8 GB the loaded LLM is also the quality translator.
- **Default image model (every tier):** Muse v3.5 Extended Q4_0, a Krea 2 fine-tune, no LoRA.
- **Out of the manifests since 2026-10-10:** stock Gemma 4, Krea 2 Turbo, the Kroma LoRA. Reports
  written before that date describe them as the defaults of their time.
- **Images:** the v7.5-1 hotfix kit (for flashed v7.5 sticks) and `kairos-hwtest-4070-v7.5-1-media.img`
  (80.5 GB, video + music pre-installed, for media of 128 GB or more) exist on the build host;
  neither is published ([how-to/BUILDING.md](how-to/BUILDING.md) §4).
- **Generation results:** a page, app or game cut at the model's length limit is served once with a
  note and never cached; a missing engine is a `503` JSON error (`REQUIREMENTS.md` R43, R67).
