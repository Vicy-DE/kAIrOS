kAIrOS — licences of the models and data (/usr/share/doc/kairos/model-licences/)

Every model or data file kAIrOS ships, or that a user downloads through it, has a folder here with its licence
text and an ATTRIBUTION / NOTICE file. The desktop lists the installed ones: About kAIrOS → Licences, or
⚙ Models & licences (GET /api/licences). index.json is the machine-readable list behind that view.
